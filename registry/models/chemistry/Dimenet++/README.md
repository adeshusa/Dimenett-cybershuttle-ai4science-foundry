Reproducible Inference: DimeNet++ on QM9Student: Adesh SrivastavaThis repository contains a fully reproducible inference workflow for evaluating the DimeNet++ Graph Neural Network on the QM9 benchmark dataset, executed on the Georgia Tech AI Makerspace (PACE ICE) cluster.1. 2. Artifact Traceability (Model, Data, & Provenance)Model Architecture: DimeNet++ (Directional Message Passing Neural Network). Implemented natively via torch_geometric.nn.models.DimeNetPlusPlus.Dataset: QM9 Benchmark. Contains ~134k small organic molecules. Automatically downloaded via torch_geometric.datasets.QM9 from the MoleculeNet DeepChem mirror.Primary Paper: Gasteiger et al., Fast and Uncertainty-Aware Directional Message Passing for Non-Equilibrium Molecules (NeurIPS 2020). Source repository: https://github.com/gasteigerjo/dimenet.Weights & Checkpoint Limitation: Currently, evaluate.py initializes the DimeNetPlusPlus architecture with untrained (randomly initialized) weights to validate the end-to-end forward-pass geometry, 3D spatial graph construction (radius_graph), and GPU tensor execution across the cluster. Because the model is evaluated without a trained checkpoint, the resulting Mean Absolute Error (MAE) on Target 7 ($U_0$) is expectedly high (12197.0133). I will release an update to this repository with instructions and support for running this workflow with loaded pre-trained weights.3. Inference Workflow & Job ScriptsThe inference pipeline is contained in evaluate.py. It constructs the 3D spatial graphs (atomic numbers and coordinates) and passes them through the DimeNet++ interaction blocks to predict physical properties.Pre-Downloading the Dataset (PACE ICE Firewall Bypass):
Compute nodes on PACE ICE may restrict outbound internet access. Before submitting the batch job, run the smoke test once on the login node (or an interactive node) to cache the ~100 MB QM9 dataset locally in ./data:
python evaluate.py --smoke-testTo run on AI Makerspace (SLURM):
Submit the job script directly to the scheduler:
sbatch run_inference.slurmThe script requests 1 standard GPU (--gres=gpu:1), 16GB of RAM, and 4 CPU cores for 30 minutes, fitting well within the 32 GPU-hour PACE ICE allocation limits.4. Validation of ResultsThis workflow includes two levels of validation, directly embedded in the execution logs:Smoke Test: Executes python evaluate.py --smoke-test. This runs a single batch of 32 molecules (724 atoms) to verify that the environment is functional, the dataset loads properly, and the output tensor shapes ([32, 1]) align without CUDA memory crashes.Substantive Validation: Executes a full evaluation over the 10,000-molecule test split targeting index 7 (Internal Energy $U_0$ at 0K). It calculates the Mean Absolute Error (MAE) across all 313 batches, verifying the directional message-passing execution across the dataset. As noted in Section 2, an MAE around 12197.0133 is expected because the model is currently loaded with untrained weights.5. Execution EvidenceExecution evidence is provided in the repository as execution_6229368.log. This file contains the node (atl1-1-01-005-9-0) and GPU (NVIDIA A40) allocation data, dataset processing milestones, expected output tensor shapes from the smoke test, and the final MAE metric (12197.0133 in 53 seconds walltime) from the substantive validation run.
